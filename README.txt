AGRO-PICK LOGIN AND REGISTER STARTER

1. Extract the AGRO-PICK.zip file.
2. Open the AGRO-PICK folder in Visual Studio Code.
3. Open index.html in your browser, or use the VS Code Live Server extension.
4. Click Get Started / Login to sign in.
5. For a new account, click Create Account or Register.
6. Register with a name, email, and password (minimum 6 characters).
7. Login using that same email and password. You will be redirected to dashboard.html.
8. Use Logout to end the demo session.

IMPORTANT SECURITY NOTE:
This is a front-end learning/demo project. It stores passwords in browser localStorage and is NOT secure for real users or public deployment. A real system needs a backend, secure password hashing, and server-side session/authentication.

Weather Map, Products, and Road Safety are starter placeholder pages. Add your actual modules and data to those pages.
